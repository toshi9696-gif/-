# writing-presentations：プレゼン・発表の読み上げ原稿

## ヒアリング（不明なら質問し、分かる範囲は仮置きで進める）
- 聞き手（社内/社外、専門知識の有無）と発表の目的（説得・報告・共有）
- 持ち時間
- 元になる資料（スライド、メモ、文書）
- 話し手の口調（です・ます調が標準）

## 原稿のルール
- **分量**：日本語は 1 分あたり約 300 字を目安に、持ち時間から総文字数を決める。
- **構成**：つかみ → 結論 → 理由・根拠 → 具体例 → まとめ（もう一度結論）→ 締め。
- **話し言葉**：1 文 40 字前後。漢語や略語は言い換えるか、初出で説明する。数字は聞き取りやすく（「約3割」など）。
- **聞き手への配慮**：「ここからは〜についてお話しします」のように、話の切り替えを言葉で示す。
- **指示記号**：`（間）`、`【強調】`、`［スライド切替］`、`（会場に問いかける）` を入れる。
- スライドの文字を読み上げるだけにせず、スライドにない補足を話す。

## 出力フォーマット
```markdown
# <発表タイトル> 読み上げ原稿（持ち時間 X 分／約 Y 字）

## スライド1：<タイトル>（目安 0:00〜0:40）
［スライド切替］
皆さん、こんにちは。……（間）……

## スライド2：……
```
最後に、各セクションの時間配分表と、想定質問と回答（Q&A）を 3〜5 個付ける。
スライド自体も必要な場合は `pptx` スキルなどと組み合わせる。
