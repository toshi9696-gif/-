# ユーザーテスト共通ルール

すべての `ut-*` スキルが従う共通ルールです。個別スキルと矛盾する場合は、このファイルを優先します。

## 用語
| 用語 | 意味 |
|---|---|
| 参加者（P1, P2…） | テストを受けるユーザー。実名は使わず ID で呼ぶ |
| モデレーター | テストを進行する人 |
| タスク | 参加者に依頼する具体的な操作（T1, T2…） |
| 発見事項（Finding） | 観察から得た問題・気づき（F-01, F-02…） |
| 深刻度 | 致命的 / 重大 / 軽微 / 改善提案 の4段階 |

## ファイル配置
テスト1回分を1フォルダにまとめる：`user-tests/YYYY-MM-DD_<テスト名>/`

| ファイル | 作成するスキル |
|---|---|
| `00_plan.md`（目的・対象者・環境・日程） | ut-setup |
| `01_scenario.md`（シナリオ・タスク・質問） | ut-scenario |
| `02_sessions/P1.md` …（観察記録） | ut-moderator |
| `03_report.md`（分析・レポート） | ut-analysis |

## 記録のルール
- 事実（参加者の発言・行動）と解釈（モデレーターの推測）を分けて書く。発言は「」で原文のまま残す。
- タイムスタンプ（mm:ss）を付ける。
- 成功判定は「成功 / 補助付き成功 / 失敗 / 中断」の4区分。

## 倫理・個人情報
- 同意取得（録画・録音・データ利用）を必ず確認項目に入れる。
- 氏名・連絡先・顔画像など個人を特定できる情報はファイルに書かない。
- 参加者を評価・批判する表現を使わない（テストするのは製品であって人ではない）。

## 文体
- 日本語、です・ます調。結論を先に書く。
- 表と箇条書きを優先し、1文は短くする。
