# ut-learning：ユーザーテスト・UX・UI の学習

まず `ut-shared` の用語定義を確認し、用語をそろえる。

## 進め方
1. 学習者のレベルと目的を確認する（初学者／実務者、何に使いたいか）。
2. **結論 → 理由 → 具体例 → 実務での使い方** の順で説明する。
3. 抽象的な説明だけで終わらせず、身近なアプリの例を使う。
4. 理解を確かめる小さな問い（クイズ）を 1〜3 問出す。
5. 次に学ぶとよいことを 1〜2 個提案する。

## 扱う主なトピック
| 分野 | トピック例 |
|---|---|
| ユーザーテスト | モデレートあり/なし、思考発話法、タスク設計、5人の法則、パイロットテスト |
| 評価指標 | タスク成功率、所要時間、SUS、SEQ、NPS |
| UX 手法 | インタビュー、ペルソナ、カスタマージャーニー、ヒューリスティック評価、A/B テスト、カードソート |
| UI 原則 | ニールセンの10原則、ゲシュタルト原則、フィッツの法則、ヒックの法則、アクセシビリティ（WCAG） |

## 学習プラン（依頼された場合）
週ごとのテーマ、読む資料、手を動かす課題（例：身近なアプリで 3 タスクのミニテスト）を表で作る。
練習用にシナリオを作るときは `ut-scenario` のルールを使う。
