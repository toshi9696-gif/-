## これからの使い方
- **毎晩**：体組成計で測ってレシートを撮影し、保存する（推定骨量と日時は手で直す）
- **運動するとき**：Apple Watch でワークアウトを開始する。心拍 120〜130 bpm を目安にする
- **日曜20時**：通知が来たら「レポート」タブで週次レポートを作成する
- **7日ごと**：アプリが開かなくなったら、iPhone を Mac につないで Xcode で `⌘` + `R`

## アプリの更新手順（参考）
1. Xcode を `⌘` + `Q` で終了し、「ダウンロード」の body-log をゴミ箱に入れる
2. ZIP をダウンロードし、展開したフォルダの名前を body-log に変える
   https://github.com/toshi9696-gif/-/archive/refs/heads/claude/health-app-body-composition-3vl4z1.zip
3. ターミナルで `cd ~/Downloads/body-log && xcodegen generate && open HealthApp.xcodeproj`
4. 実行先が自分の iPhone になっていることを確認して `⌘` + `R`
