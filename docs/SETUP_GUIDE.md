# はじめての動かし方ガイド（非エンジニア向け）

所要時間の目安：初回 60〜90 分（ほとんどがダウンロード待ち）

## 全体の流れ

| 段階 | やること | 1回だけ / 毎回 |
|---|---|---|
| 準備 | ① Xcode を入れる　② Homebrew と XcodeGen を入れる | 1回だけ |
| 取得 | ③ アプリの設計図（ソースコード）を Mac に持ってくる | 更新のたび |
| 組み立て | ④ Xcode 用のプロジェクトを作る | 更新のたび |
| 実行 | ⑤ Xcode で iPhone に入れる | 更新のたび |

---

## ① Xcode を入れる（1回だけ）

1. Mac の **App Store** を開き、「Xcode」で検索して入手する（約 10GB。時間がかかります）。
2. 入ったら Xcode を一度起動する。「追加コンポーネントをインストールしますか」と出たら **Install** を押す。
3. iOS の部品を選ぶ画面が出たら **iOS** にチェックを入れて進む。
4. 上部メニューの **Xcode → Settings（設定）→ Accounts** を開き、左下の「＋」→「Apple ID」で、Apple Developer に登録した Apple ID でサインインする。
5. Xcode はいったん閉じてよい。

## ② Homebrew と XcodeGen を入れる（1回だけ）

ここからは「ターミナル」を使います。

- **ターミナルの開き方**：`command ⌘` + `スペース` を押し、「ターミナル」と入力して Enter。
- **使い方**：下の灰色の枠の文字をコピーし、ターミナルに貼り付けて **Enter**。
  処理が終わると、行の先頭に `%` や `$` が出て、次の入力を待つ状態に戻ります。それまで待ってください。

### 2-1. Homebrew が入っているか確認

```
brew --version
```

- `Homebrew 4.x.x` のように表示された → **2-3 へ**
- `command not found` と表示された → **2-2 へ**

### 2-2. Homebrew を入れる

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

- 「Password:」と出たら、**Mac のログインパスワード**を入力して Enter（入力しても画面には何も表示されませんが、正常です）。
- 「Press RETURN to continue」と出たら Enter。
- 最後に **「Next steps」** という見出しと、2〜3 行のコマンドが表示されます。それも 1 行ずつコピーして実行してください。
- 実行したら、2-1 のコマンドをもう一度試して、バージョンが出ることを確認する。

### 2-3. XcodeGen を入れる

```
brew install xcodegen
```

## ③ ソースコードを Mac に持ってくる

### 方法 A：ブラウザでダウンロード（おすすめ・簡単）

1. ブラウザで GitHub にログインした状態で、次のリンクを開く。ZIP ファイルがダウンロードされます。
   https://github.com/toshi9696-gif/-/archive/refs/heads/claude/health-app-body-composition-3vl4z1.zip
2. ダウンロードフォルダの ZIP をダブルクリックして展開する。
3. できたフォルダの名前を **body-log** に変更し、「書類」フォルダなど分かりやすい場所に移す。

アプリを更新したときは、古い body-log フォルダを削除して、同じ手順でもう一度ダウンロードしてください。

## ④ Xcode 用のプロジェクトを作る

1. ③ で名前を **body-log** に変えたフォルダが「ダウンロード」フォルダにあることを Finder で確認する。
   （フォルダを別の場所に移した場合は、いったん「ダウンロード」に戻すと手順どおりに進められます）
2. キーボードの **「英数」キー** を押して、日本語入力をオフにする。
   日本語入力のままだとスペースが全角になり、`command not found` というエラーになります。
3. 次をコピーして貼り付け、Enter。
   ```
   cd ~/Downloads/body-log
   ```
   エラーが出ずに、行の先頭が `body-log %` に変われば成功です。
4. 次を実行する。
   ```
   xcodegen generate
   ```
   `Created project at ... HealthApp.xcodeproj` と出れば成功です。
5. 次を実行すると Xcode が開きます。
   ```
   open HealthApp.xcodeproj
   ```

## ⑤ iPhone に入れて動かす

### 5-1. 署名（だれが作ったアプリか）を設定する

1. Xcode の左の一覧の一番上、青いアイコンの **HealthApp** をクリック。
2. 中央の上部にある **Signing & Capabilities** タブをクリック。
3. **Team** のプルダウンで、自分の名前（Personal Team ではない方）を選ぶ。
4. 赤いエラー表示が消えれば OK。

### 5-2. iPhone の準備

1. iPhone を **ケーブルで Mac につなぐ**。iPhone に「このコンピュータを信頼しますか？」と出たら **信頼**。
2. iPhone の **設定 → プライバシーとセキュリティ → デベロッパモード** をオンにする（再起動を求められたら従う）。
   ※ この項目は、一度 Xcode につないだ後に表示されることがあります。見つからなければ 5-3 を先に試してください。

### 5-3. 実行

1. Xcode 画面の上部中央にある実行先（「iPhone 16」などの表示）をクリックし、**自分の iPhone** を選ぶ。
2. 左上の **▶（再生ボタン）** を押す。
3. 初回は数分かかります。iPhone にアプリ「体組成ログ」が起動すれば成功です。

## ⑥ アプリを試す

1. 右上の **カメラボタン** → レシートを写す → 自動で枠が取れたら「保存」。
2. 「読み取り結果」画面で、上部の **チェック結果** が緑か赤かを確認する。
3. 右上の「保存」を押す。初回はヘルスケアへのアクセス許可画面が出るので、**すべてオン** にして「許可」。
4. 一覧に記録が出て、ハートマークが付けばヘルスケアにも記録されています。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| `command not found: xcodegen` | ② をやり直す。2-2 の「Next steps」のコマンドを実行し忘れていることが多い |
| `zsh: command not found: cd　…` | 日本語入力のままで、スペースが全角になっている。「英数」キーを押してから ④-3 をやり直す |
| `No project spec found` / `Spec file not found` | body-log フォルダに移動できていない。④-1 からやり直す |
| Xcode で「Signing for "HealthApp" requires a development team」 | 5-1 の Team を選ぶ |
| 「Failed to register bundle identifier」 | `project.yml` の `com.toshi9696.bodylog` を別の名前（例：`com.toshi9696.bodylog2`）に変えて ④-3 からやり直す |
| iPhone が実行先に出てこない | ケーブルをつなぎ直す、iPhone のロックを解除する、5-2 のデベロッパモードを確認する |
| 赤い文字のビルドエラー | エラー文をコピーするかスクリーンショットを撮って、Claude に送る |

困ったら、**どの番号の手順で、画面に何と表示されたか** をそのまま送ってください。
