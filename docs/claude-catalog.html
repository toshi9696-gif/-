Claude スキル＆ルール台帳

Claude Code（リポジトリ toshi9696-gif/-）で使えるルールの仕組みとスキルをまとめた一覧です。Cursor・ChatGPT から移行した自作スキル 7 件も含みます。

ルール

Claude の振る舞いを常に制御する設定ファイルです。「状態」はこのリポジトリでの現状です。

種類置き場所役割適用範囲状態

スキル

特定の作業向けの手順をまとめたものです。/スキル名 で呼び出すか、依頼内容に合わせて Claude が自動で使います。緑の線は自作スキルです。

自作スキルを他の環境で使う

自作スキルは現在このリポジトリの .claude/skills/ にあり、このリポジトリを開いた Claude Code で使えます。

Mac の Claude Code（全プロジェクト）

.claude/skills/ の各フォルダを ~/.claude/skills/ にコピーします。

claude.ai・デスクトップアプリ

設定 → 機能 → スキル から dist/claude-skills/ の ZIP を1つずつアップロードします。

中身の調整

元の Cursor／ChatGPT 版の詳しい指示がある場合は、各 SKILL.md に追記すると精度が上がります。

2026年10月18日時点のクラウドセッション環境をもとに作成。使えるスキルはアカウント、有効なプラグイン、利用環境（CLI／デスクトップ／Web）によって変わります。
